# 🎨 个人菜谱小程序 UI 设计规范 (Design System)

**版本**: v1.1
**更新日期**: 2026-02-04
**适用技术栈**: 微信小程序原生 / WXML / WXSS

---

## 1. 设计理念 (Design Philosophy)

本项目的 UI 旨在传达一种“**电子手账**”般的精致与温情，区别于传统工具类应用的冷硬感。

*   **核心关键词**：
    *   ☀️ **温暖 (Warm)**：低饱和度的暖色调，激发食欲与归属感。
    *   🍃 **呼吸感 (Airy)**：大面积留白，去线化设计，拒绝拥挤。
    *   ⚪ **圆润 (Rounded)**：大圆角卡片，亲和力强，无锐利棱角。
    *   ✨ **微质感 (Texture)**：模拟纸张的米白背景，配合毛玻璃效果。

## 2. 色彩系统 (Color Palette)

### 2.1 主色调 (Primary)
用于核心操作、高亮状态、重要图标。

| 色值 | 变量名 | 说明 |
| :--- | :--- | :--- |
| **#FF9F7F** | `--color-primary` | **暖柿色**。核心品牌色，温暖且有食欲。 |
| **#E88D6E** | `--color-primary-dark` | 点击态 (Active)。加深 10%。 |
| **rgba(255, 159, 127, 0.15)** | `--color-primary-light` | 浅色底。用于次级按钮、标签背景。 |

### 2.2 背景色 (Background)
**注意**：不要使用纯白 `#FFFFFF` 作为全屏背景。

| 色值 | 变量名 | 说明 |
| :--- | :--- | :--- |
| **#FAFAF8** | `--bg-color` | **米白/蛋壳青**。全局页面背景，护眼且有质感。 |
| **#FFFFFF** | `--card-bg` | **纯白**。用于卡片、弹窗，承载内容。 |
| **#F5F5F5** | `--bg-color-grey` | 淡灰。用于分割线、ID标签背景。 |

### 2.3 文字色 (Typography)

| 色值 | 变量名 | 说明 |
| :--- | :--- | :--- |
| **#333333** | `--text-main` | 主要文字 (标题)。 |
| **#666666** | `--text-sub` | 常规文字 (正文)。 |
| **#999999** | `--text-light` | 辅助文字 (说明、日期)。 |
| **#CCCCCC** | `--text-placeholder` | 占位符、不可用状态。 |

### 2.4 功能色 (Functional)

| 色值 | 变量名 | 说明 |
| :--- | :--- | :--- |
| **#FF6B6B** | `--color-error` | 喜欢、收藏、删除。 |
| **#FFC800** | `--color-warning` | 草稿、提醒。 |
| **#36A2EB** | `--color-link` | 链接、社交互动。 |

## 3. 字体排版 (Typography)

全站优先使用系统默认字体（PingFang SC / HarmonyOS Sans）。  
数字推荐使用圆润字体（如 Nunito），若无则加粗系统字体。

| 类型 | 字号 (rpx) | 字重 | 行高 | 适用场景 |
| :--- | :--- | :--- | :--- | :--- |
| **超大标题** | `42rpx` | 700 (Bold) | 1.1 | 个人主页昵称、详情页大标题 |
| **页面标题** | `34rpx` | 600 (Semi) | 1.4 | 导航栏标题、板块标题 |
| **卡片标题** | `30rpx` | 600 (Semi) | 1.5 | 列表卡片标题 |
| **正文/输入** | `28rpx` | 400 (Regular)| 1.6 | 详情页正文、输入框文字 |
| **次级信息** | `26rpx` | 400 | 1.4 | 简介、列表标签文字 |
| **辅助/说明** | `22rpx` | 400 | 1.2 | 日期、点赞数、底部 Slogan |
| **极小标签** | `20rpx` | 500 | 1.0 | 图片上的 Tag、角标 |

## 4. 布局与间距 (Layout)

### 4.1 圆角 (Border Radius)
*   **卡片/弹窗**: `24rpx` (`--radius-lg`) - **核心特征**
*   **输入框/大图**: `16rpx` (`--radius-base`)
*   **小标签**: `8rpx` (`--radius-sm`)
*   **按钮/胶囊**: `999rpx` (`--radius-capsule`)

### 4.2 阴影 (Shadows)
*   **Level 1 (静止)**: `0 4rpx 12rpx rgba(0,0,0,0.03)`
*   **Level 2 (悬浮/点击)**: `0 8rpx 24rpx rgba(0,0,0,0.06)`
*   **Diffuse (弥散光)**: `0 8rpx 20rpx rgba(255, 159, 127, 0.3)` (仅用于主按钮)

## 5. 组件规范 (Component Specs)

### 🏷️ 标签 (Tags)
1.  **图片覆盖标签 (Overlay Tag)**:
    *   背景: `rgba(0,0,0,0.45)` + `backdrop-filter: blur(4px)`
    *   文字: 白色, `20rpx`
    *   描边: `1rpx solid rgba(255,255,255,0.1)`
2.  **筛选标签 (Filter Tag)**:
    *   未选中: 白底, 灰字, Level 1 阴影。
    *   选中: 主色底, 白字, Diffuse 阴影。

### 🃏 卡片 (Cards)
*   背景色必须为 **纯白 (#FFFFFF)**。
*   必须设置 `overflow: hidden` 以保证图片圆角。
*   **交互**: 添加点击缩放效果 (`transform: scale(0.98)` 或位移)。

### 🔘 按钮 (Buttons)
*   **主按钮 (FAB/Submit)**:
    *   背景: 线性渐变 `linear-gradient(135deg, #FF9F7F, #FF8E66)`
    *   阴影: Diffuse 阴影。

## 6. 页面开发检查清单 (Checklist)

在开发新页面（如详情页、编辑页）时，请对照此清单：

1.  [ ] **背景检查**：页面最外层容器是否使用了 `--bg-color` (#FAFAF8)？避免使用死白。
2.  [ ] **去线化**：是否尽量通过 **间距(Margin)** 和 **背景色块** 来区分内容，而不是使用横线边框？
3.  [ ] **呼吸感**：主要内容块之间是否保留了至少 `20rpx - 30rpx` 的间距？
4.  [ ] **对齐**：卡片内的文字是否遵循了 **左对齐** 原则？
5.  [ ] **微交互**：可点击区域（卡片、按钮）是否添加了 `hover-class` 效果？
6.  [ ] **空状态**：数据为空时，是否展示了友好的提示文案，而不是一片空白？
